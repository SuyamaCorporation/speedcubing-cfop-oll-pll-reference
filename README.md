# スピードキュービング CFOP/OLL・PLL アルゴリズム早見表

57種のOLLと21種のPLLアルゴリズムをSVG図解付きで一覧表示するリファレンスアプリです。ケース名やアルゴリズム表記で検索・フィルタリングができ、苦手なケースに「弱点」タグを付けてlocalStorageで管理できます。

## 機能
- OLL（57ケース）/ PLL（21ケース）のタブ切り替え表示
- 各ケースのSVG上面パターン図解とアルゴリズム表記
- ケース名・アルゴリズムのキーワード検索
- 弱点タグ付けボタン（1クリック、localStorage永続化）
- 「弱点のみ表示」フィルタートグル
- モバイル対応レスポンシブレイアウト
